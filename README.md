# Devon & Brianna — Elopement website

## Publish on GitHub Pages
1. Unzip this package. Upload the contents directly to your repository root so index.html is at the root (not in an extra folder).
2. In repository Settings → Pages, choose Deploy from a branch, then your main branch and / (root). Save.
3. Visit the URL GitHub provides after deployment completes.

This is a static website: no installation, build, account, or password is required. Relative asset links support both user and project GitHub Pages sites.

## Photos
All 100 images from photos.zip appear in gallery.html in numeric order. Each has an 800px thumbnail and a 2200px large WebP image (maximum long edge), with original orientation applied and embedded metadata removed. The gallery works without JavaScript as links to large images; with JavaScript it provides a keyboard-accessible viewer (Escape closes, arrows navigate). Thumbnails load lazily. The original full-resolution files are intentionally not included.
